## Must-Read Research Papers

- [Attention Is All You Need (Google)](https://arxiv.org/pdf/1706.03762) — The paper that introduced the Transformer architecture
- [Language Models are Few-Shot Learners – GPT-3 (OpenAI)](https://arxiv.org/abs/2005.14165) — Introduces GPT-3, a 175B parameter model demonstrating strong few-shot learning across NLP tasks
- [Chain-of-Thought Prompting Elicits Reasoning in Large Language Models (Google)](https://arxiv.org/abs/2201.11903) — Introduces chain-of-thought prompting, showing intermediate reasoning steps significantly improve LLM performance on complex tasks
- [DeepSeek R1: Incentivizing Reasoning Capability in LLMs](https://arxiv.org/pdf/2501.12948) — Paper detailing DeepSeek's reasoning-focused R1 model trained with reinforcement learning
- [Monolith: Real Time Recommendation System (TikTok/ByteDance)](https://arxiv.org/pdf/2209.07663) — TikTok/ByteDance's paper on their real-time recommendation system
- [BERT: Pre-training of Deep Bidirectional Transformers](https://arxiv.org/pdf/1810.04805) — Paper introducing BERT, a bidirectional transformer for language understanding
- [Understanding Deep Learning Requires Rethinking Generalization](https://arxiv.org/pdf/1611.03530) — Paper challenging traditional views of generalization in deep learning
- [Playing Atari with Deep Reinforcement Learning](https://arxiv.org/pdf/1312.5602) — DeepMind's paper introducing deep Q-networks for Atari games
- [Distilling the Knowledge in a Neural Network](https://arxiv.org/pdf/1503.02531) — Hinton et al.'s paper introducing knowledge distillation
